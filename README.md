# 대대일지 · Battalion Chronicle

1936–1945년을 배경으로 하는 한국어 싱글 플레이 대대 지휘 시뮬레이션입니다.

- 이름과 6개 얼굴 커스터마이징, 고정 기초 능력치
- 보병·기갑·기병 병과와 개인 특성 추첨, 병과에 맞는 부대 배정
- 1936년 1월 또는 1939년 8월 시작
- 월간 지휘 기회, 중대 임무 변경, 지원 소대 개편
- 예산과 평판에 따른 보급 요청·심사·배송
- 역사적 시기를 따르는 전선 배속과 무작위 사건
- 전술별 승률과 인명·장비 손실, 철수 선택
- 자동 저장, JSON 내보내기·불러오기, 1945년 5월 결말
- 데스크톱·모바일 지원 및 키보드 접근 가능한 모달

실존 상급부대 이름을 바탕으로 가상 대대의 배속과 사건을 재구성합니다. 정확한 편제·작전 지도 재현을 표방하지 않으며 지도를 사용하지 않습니다. 스페인 사건은 대대 전체가 아닌 교관·연락장교 소규모 파견입니다. 전쟁의 역사적 종결은 플레이어 전투 결과와 별개로 고정됩니다.

## 실행

Node.js 20 이상과 로컬 미리보기를 위한 Python 3이 필요합니다. 런타임 및 빌드 의존 패키지는 없습니다.

```sh
npm run dev
npm test
npm run build
```

`http://localhost:3000`에서 플레이합니다. Vercel은 `npm run build`로 `public/`을 `dist/`에 복사하여 정적 배포합니다. 저장은 브라우저 localStorage를 사용하므로 기기 간 이동 시 기록을 JSON 파일로 내보낸 뒤 불러오세요.

폰트는 Google Fonts를 사용하며 연결이 불가능하면 시스템 글꼴로 표시됩니다. 인물과 주둔지 삽화는 자체 SVG로 포함되어 있습니다.

## 구성

- `public/engine.mjs`: 시드 난수, 대대 상태, 전투, 전역과 사건
- `public/app.mjs`: 화면과 상호작용, 저장과 파일 입출력
- `public/style.css`: 반응형 스타일
- `tests/engine.test.mjs`: 규칙·자원·저장·48개 전체 복무 시뮬레이션 검증
- `vercel.json`: 정적 배포 설정
